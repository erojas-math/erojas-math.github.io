# Edgar Rojas — Academic Portfolio

A multi-page academic website designed for PhD applications and hosted free with GitHub Pages at `https://erojas-math.github.io`.

## Update the site

Edit the relevant HTML page in GitHub and commit the change; the live website will update automatically. The site includes separate Home, Research, Teaching, and Notes pages.

Public PDFs are stored in the `assets` folder. The site links to the CV at `assets/Edgar_Rojas_CV.pdf` and the thesis at `assets/EdgarRojas_Thesis2025.pdf`.

## Publish with GitHub Pages

1. Create a public GitHub repository named `erojas-math.github.io`.
2. Upload every file and folder in this project to the repository.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. The site will appear at `https://erojas-math.github.io` after GitHub finishes deploying it.

## Privacy

The website intentionally omits the street address and telephone number from the source CV.
